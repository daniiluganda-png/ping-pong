# ping-pong
в репозитории пинг-понг лежит мультиплеерная игра "пинг-понг"
она сделана на языке python с помощью библиотеки pygame
управление:игрок 1 управляют ракеткой клавишами игрок 2 управляет ракеткой клавишами

Le dépôt Ping-Pong contient un jeu multijoueur appelé « Ping-Pong ».

Il est écrit en Python avec la bibliothèque pygame.

Commandes : Le joueur 1 contrôle la raquette avec les touches [touches 1] et le joueur 2 avec les touches [touches 2].
